# CH32H417 DFSDM（数字滤波器 Σ-Δ 调制器）学习笔记

> 目标外设：**DFSDM**（Digital Filter for Sigma-Delta Modulators）
> 这是 STM32H7 系列同款外设的 WCH 实现 —— 用于把 **Σ-Δ 调制器**（如麦克风、电表、称重传感器）输出的**位流（bit-stream）**通过**数字滤波 + 抽取**转换成**高精度 PCM 数据**。
>
> CH32H417 的 DFSDM 资源：**2 个通道（CH0/CH1）** + **2 个滤波器（FLT0/FLT1）**

---

## 二、DFSDM 硬件基础

### 2.1 资源映射（CH32H417）

| 资源 | 地址 | 说明 |
|---|---|---|
| `DFSDM_Channel0` | `0x40017000` | 通道 0 |
| `DFSDM_Channel1` | `0x40017004` | 通道 1 |
| `DFSDM_FLT0`     | `0x40017028` | 滤波器 0（支持 RC + JC） |
| `DFSDM_FLT1`     | `0x4001702C` | 滤波器 1（支持 RC + JC） |
| **DMA Mux ID 107** | — | DFSDM_FLT0 数据请求 |
| **DMA Mux ID 108** | — | DFSDM_FLT1 数据请求 |

### 2.2 DFSDM 三层结构

```
Σ-Δ 调制器 / 内部源
       │ (位流 bit-stream)
       ▼
┌──────────────────────────┐
│    Channel（通道层）     │  ← 串行时钟配置、数据打包、短路检测
└──────────────────────────┘
       │
       ▼
┌──────────────────────────┐
│    Filter（滤波器层）    │  ← Sinc 滤波器 + 积分器 + 模拟看门狗
└──────────────────────────┘
       │
       ▼
┌──────────────────────────┐
│  Conversion（转换层）    │  ← Regular（RC）/ Injected（JC），DMA / 中断
└──────────────────────────┘
       │
       ▼
  RDATAR（32-bit 结果）
```

### 2.3 三种数据源（来自 `DFSDM_ChDataMultiplexer`）
```c
DFSDM_InternalInput   // 内部并行数据（CPU 推数据进 Channel）
DFSDM_SerialInput     // 外部串行输入（Σ-Δ 调制器 / PDM 麦克风）
DFSDM_ADCInput        // 内部 ADC 直通
```

### 2.4 三种数据打包模式（`DFSDM_ChDataPackMode`）
| 模式 | 数据格式 | 写入 API |
|---|---|---|
| **StandardMode** | 单个 int16 | `DFSDM_WriteParallelDataStanMode(CH, data16)` |
| **InterleaveMode** | 双 int16 交替（左右声道 PDM） | `DFSDM_WriteParallelDataIntlMode(CH, data16_l, data16_r)` |
| **DualMode** | 双 int16 同时（FLT0/FLT1 同步读） | `DFSDM_WriteParallelDataDualMode(CH0, data16_0, data16_1)` |

### 2.5 两种转换方式
- **Regular Conversion（RC）**：连续 / 触发 / 软件启动 → 结果在 `RDATAR`
- **Injected Conversion（JC）**：由定时器 / EXTI / 软件触发 → 适合"按需采样"

### 2.6 滤波器参数
- **Sinc 阶数**：`Sinc1 / Sinc2 / Sinc3 / Sinc4 / Sinc5 / FastSinc / Bypass`
- **过采样率**（OSR）：1~1024，越大精度越高、输出速率越低
- **积分过采样率**（IOSR）：1~1024，作为二级抽取

输出采样率公式：
```
f_OUT = f_CLKIN / (OSR × (Sinc_order + 2) + IOSR)
```

### 2.7 模拟看门狗（AWD）
- 监测 FLT 输出是否超 [Low, High] 阈值
- 可配置 Break 信号（用于紧急切断）
- 在 SerialSPI 示例中使用

## 四、各示例详解

### 4.1 `DFSDM_InternalStandardMode` —— 内部并行 + 标准模式（最简）

```c
// 通道：标准模式，内部输入，选择当前通道
DFSDM_ChannelInitStructure.DFSDM_ChDataPackMode     = DFSDM_StandardMode;
DFSDM_ChannelInitStructure.DFSDM_ChDataMultiplexer  = DFSDM_InternalInput;
DFSDM_ChannelInitStructure.DFSDM_ChInPinSelect      = DFSDM_SelectCurrent;
DFSDM_ChannelInitStructure.DFSDM_ChDataRightBitShift = 3;

// 滤波器：Sinc3，OSR=32，IOSR=1
DFSDM_FilterInitStructure.DFSDM_FltSincOrder           = DFSDM_FLT_Sinc3;
DFSDM_FilterInitStructure.DFSDM_FltOverSample          = FLT_Over_Sample;  // 32
DFSDM_FilterInitStructure.DFSDM_FltIntegratorOverSample = 1;

// RC 连续转换 + DMA
DFSDM_RcInitStructure.DFSDM_RcChannel          = DFSDM_RC_Channel0;
DFSDM_RcInitStructure.DFSDM_RcContinuousMode   = ENABLE;
DFSDM_RcInitStructure.DFSDM_RcSynchronousMode  = DISABLE;
DFSDM_RcInitStructure.DFSDM_RcFastMode         = DISABLE;
DFSDM_RcInitStructure.DFSDM_RcDMAMode          = ENABLE;

// 主循环：等 RCIP 标志 → 写入 1 个 int16
while (DFSDM_GetFlagStatus(DFSDM_FLT0, DFSDM_FLAG_FLTx_RCIP) == RESET);
DFSDM_WriteParallelDataStanMode(DFSDM_Channel0, Txdata[i]);
```

数据流：
```
Txdata[i]  → [StanMode] → Channel0 → FLT0 → DMA → Rxdata[]
```

### 4.2 `DFSDM_InternalDualMode` —— 双模式同步
```c
// 通道 0 用 DualMode（带双 int16），通道 1 也独立
DFSDM_ChannelInitStructure.DFSDM_ChDataPackMode = DFSDM_DualMode;  // Ch0
DFSDM_ChannelInitStructure.DFSDM_ChDataPackMode = DFSDM_StandardMode;  // Ch1
// FLT0 用 Ch0，FLT1 用 Ch1，但同步写入
DFSDM_WriteParallelDataDualMode(DFSDM_Channel0, TxdataFlt0[i], TxdataFlt1[i]);
```
> 一次写入 → 两路并行采集 → FLT0/FLT1 各出结果。

### 4.3 `DFSDM_InternalInterleavedMode` —— 交错模式（PDM 麦克风原理）
```c
DFSDM_ChannelInitStructure.DFSDM_ChDataPackMode = DFSDM_InterleaveMode;
// 一次写左右两个 int16（交错合并到一个 32-bit 数据流）
DFSDM_WriteParallelDataIntlMode(DFSDM_Channel0, Txdata[2*i], Txdata[2*i+1]);
```
> 类似 PDM 双声道麦克风的串行流（左/右各占 1 个 bit）。

### 4.4 `DFSDM_InternalADC` —— 内部 ADC → DFSDM 直通
```c
// 关键：把 ADC 数据直接路由给 DFSDM，无须 CPU 介入
ADC_RegularChannelConfig(ADC1, ADC_Channel_8, 1, ADC_SampleTime_CyclesMode7);
ADC_TO_DFSDM_Cmd(ADC1, ENABLE);  // ADC → DFSDM 通道

// DFSDM 通道选 ADC 输入
DFSDM_ChannelInitStructure.DFSDM_ChDataMultiplexer = DFSDM_ADCInput;
DFSDM_RcInitStructure.DFSDM_RcFastMode = ENABLE;  // 不开 DMA，直接读
while (DFSDM_GetFlagStatus(DFSDM_FLT0, DFSDM_FLAG_FLTx_REOCF) == SET) {
    value = DFSDM_RcReadConvData(DFSDM_FLT0);
}
```
> 应用场景：内置 ADC + DFSDM 实现 **过采样 + 数字滤波**，比单纯 ADC 多出 4~12 bit 精度。

### 4.5 `DFSDM_SerialSPI` —— 外部 Σ-Δ 调制器（最实用）

```c
// 引脚：CKIN0-PC0(AF3), DATIN0-PC1(AF3)
GPIO_PinAFConfig(GPIOC, GPIO_PinSource0, GPIO_AF3);
GPIO_PinAFConfig(GPIOC, GPIO_PinSource1, GPIO_AF3);

// 通道：标准模式 + 串行输入 + 短路检测 + 外部时钟
DFSDM_ChannelInitStructure.DFSDM_ChDataPackMode         = DFSDM_StandardMode;
DFSDM_ChannelInitStructure.DFSDM_ChDataMultiplexer      = DFSDM_SerialInput;
DFSDM_ChannelInitStructure.DFSDM_ChShortCircuitDetMode  = ENABLE;
DFSDM_ChannelInitStructure.DFSDM_ChClockAbsenceDetMode  = DISABLE;
DFSDM_ChannelInitStructure.DFSDM_ChSerialInterface      = DFSDM_ExternalClkIn;
DFSDM_ChannelInitStructure.DFSDM_ChSPIClockSource       = DFSDM_SPIRising;
DFSDM_ChannelInitStructure.DFSDM_ChSCDCntthreshold      = 220;

// 模拟看门狗
DFSDM_FilterInitStructure.DFSDM_FltAWDChannel        = DFSDM_AWD_Channel0;
DFSDM_FilterInitStructure.DFSDM_FltAWDHighThreshold  = 32768;
DFSDM_FilterInitStructure.DFSDM_FltAWDLowThreshold   = -32768;

// SPI2 模拟外部调制器的位流（测试用）
// 实际硬件：Σ-Δ 调制器（如 MP45DT02、ADS1251）连接到 CKIN/DATIN
```

**实测数据**：
```c
// AWD 中断（短路或超阈值）会置位 ErrorFlag
void DFSDM0_IRQHandler(void) {
    if (DFSDM_GetITStatus(DFSDM_FLT0, DFSDM_IT_FLAG_FLTx_AWDF)) {
        ErrorFlag = 1;
        printf("Exceeded the threshold!\r\n");
    }
    if (DFSDM_GetITStatus(DFSDM_FLT0, DFSDM_IT_FLAG_FLT0_SCDF0)) {
        ErrorFlag = 1;
        printf("Short-circuit detected!\r\n");
    }
}
```

### 4.6 `DFSDM_DualFliter` —— 双滤波器并行
- FLT0 用 Channel0，FLT1 用 Channel1
- 两个滤波器各自独立工作，可接两个传感器
- 双 DMA 流（DMA1 Ch1 / Ch2 + Mux 107/108）

### 4.7 `DFSDM_Synchronous_Regular` —— 双滤波器同步
- **关键差异**：
  ```c
  DFSDM_RcInitStructure.DFSDM_RcChannel          = DFSDM_RC_Channel0;
  DFSDM_RcInitStructure.DFSDM_RcSynchronousMode  = DISABLE;  // FLT0 独立
  DFSDM_RcInit(DFSDM_FLT0, ...);
  
  DFSDM_RcInitStructure.DFSDM_RcChannel          = DFSDM_RC_Channel1;
  DFSDM_RcInitStructure.DFSDM_RcSynchronousMode  = ENABLE;   // FLT1 同步
  DFSDM_RcInit(DFSDM_FLT1, ...);
  ```
- FLT1 与 FLT0 同步触发 / 同步读

### 4.8 `DFSDM_EXTITrigger` —— 外部中断触发注入转换

```c
// EXTI11 配置为事件模式 → 触发 DFSDM 注入转换
EXTI_InitStructure.EXTI_Line    = EXTI_Line11;
EXTI_InitStructure.EXTI_Mode    = EXTI_Mode_Event;     // 注意：Event 而不是 Interrupt
EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;
EXTI_Init(&EXTI_InitStructure);

// DFSDM 注入转换配置
DFSDM_JcInitStructure.DFSDM_JcChannelGroup   = DFSDM_JC_Channel0;
DFSDM_JcInitStructure.DFSDM_JcDMAMode        = DISABLE;
DFSDM_JcInitStructure.DFSDM_JcSynchronousMode = DISABLE;
DFSDM_JcInitStructure.DFSDM_JcScanMode       = DISABLE;
DFSDM_JcInitStructure.DFSDM_JcTriggerEdge    = DFSDM_JC_Trigger_Rising;
DFSDM_JcInitStructure.DFSDM_JcTriggerSignal  = DFSDM_JC_Trigger_EXTI11;

// 主循环：查询 JEOCF 标志 → 读注入转换结果
while (DFSDM_GetFlagStatus(DFSDM_FLT0, DFSDM_FLAG_FLTx_JEOCF) == SET) {
    value = DFSDM_JcReadConvData(DFSDM_FLT0);
}
```

### 4.9 `DFSDM_TIMTrigger` —— 定时器触发

```c
// TIM2 配置：96 Hz 触发（9600 / 10000 / 4800）
TIM_SelectOutputTrigger(TIM2, TIM_TRGOSource_Update);

// DFSDM 用 TIM2 作为注入触发源
DFSDM_JcInitStructure.DFSDM_JcTriggerSignal = DFSDM_JC_Trigger_TIM2;
```

支持的 JC 触发源：
```c
DFSDM_JC_Trigger_TIM1~12 / EXTI11 / EXTI15 / LPTIM1 / LPTIM2
```

### 4.10 `DFSDM_I2S_Audio` —— PDM 麦克风 + I2S 输出

**典型应用**：PDM 数字麦克风 → DFSDM 解调 → I2S 输出给 DAC 或功放

```c
// 数据流
// PDM Mic → DFSDM (CKOUT 内部时钟 16 MHz / ClkoutDiv=195)
//         → Sinc3 滤波器 (OSR=128, IOSR=0)
//         → DMA → PCM 16-bit 数据
//         → I2S1 Master → 耳机/音箱

// 引脚分配
// DFSDM_CKOUT = PC2(AF6)   ← 输出给 PDM 麦克风的时钟
// DFSDM_DATIN1 = PC3(AF3)  ← 接收 PDM 数据
// I2S_WS = PB12(AF5)
// I2S_CK = PB13(AF5)
// I2S_SD = PC1(AF5)
// I2S_MCK = PC6(AF5)

// DMA 循环模式 + Half-Transfer / Full-Transfer 中断
DMA_InitStructure.DMA_Mode = DMA_Mode_Circular;

// 关键：使用双缓冲切换
while (DMA 半满) → 读前半 → 清标志
while (DMA 全满) → 读后半 → 清标志
```

### 4.11 `DFSDM_SAI_Audio` —— PDM 麦克风 + SAI 输出

同 4.10，但用 **SAI**（Serial Audio Interface）替代 I2S：
```c
// 引脚
// DFSDM_CKOUT = PB0(AF6)
// DFSDM_DATIN1 = PB12(AF6)
// SAI_FS_A   = PC3(AF7)
// SAI_SCK_A  = PC2(AF7)
// SAI_SD_A   = PB2(AF6)
// SAI_MCLK_A = PE2(AF6)

// SAI 配置
SAI_InitStructure.SAI_AudioMode = SAI_Mode_MasterTx;
SAI_InitStructure.SAI_Protocol  = SAI_Free_Protocol;
SAI_InitStructure.SAI_DataSize  = SAI_DataSize_16b;
SAI_InitStructure.SAI_FIFOThreshold = SAI_FIFOThreshold_HalfFull;
```

> SAI 比 I2S 更强大，支持 TDM 多声道。

## 五、关键工程参数

### 5.1 时钟配置
```c
// 系统时钟 → DFSDM 时钟源
RCC_HB2PeriphClockCmd(RCC_HB2Periph_DFSDM, ENABLE);

// 输出串行时钟给外部调制器
DFSDM_OutSerialClkConfig(DFSDM_AudioClk, ClkoutDiv);
// 例如：f_AudioClk = 16 MHz, ClkoutDiv=195 → 实际 CKOUT ≈ 82 kHz
```

### 5.2 DMA 通道映射
| 外设 | DMA Mux ID | DMA 通道 |
|---|---|---|
| `DFSDM_FLT0` (RDATAR) | **107** | DMA1_Channel1 |
| `DFSDM_FLT1` (RDATAR) | **108** | DMA1_Channel2 |
| `SPI2` TX (测试用) | **65**  | DMA1_Channel1 |
| `ADC1` | **0x78** | DMA1_Channel1 |

### 5.3 缓冲区尺寸计算
```c
#define FlT_Sinc_Order    DFSDM_FLT_Sinc3   // 3
#define FLT_Over_Sample   32                  // OSR
#define RxBuffSize        10
#define TxbuffSize        ((FLT_Over_Sample * (2 + FlT_Sinc_Order + 1) + 2) * RxBuffSize)
// = (32 * (2 + 3 + 1) + 2) * 10 = 32 * 6 * 10 + 20 = 1940
```
> **每输出 1 个样本需要 OSR × (Sinc_order + 2) 次串行采样**（对内部测试还需 +2 间隙）。

### 5.4 数据右移（DFSDM_ChDataRightBitShift）
- 输出结果可右移 N 位降低量级
- 典型值：内部测试用 3~8；PDM 音频用 2；ADC 直通用 8

## 七、典型应用场景

### 7.1 PDM 麦克风录音
```
PDM Mic (1~2 路) → DFSDM (Sinc3 + 抽取) → DMA → PCM 数据 → I2S/SAI → DAC/音箱
```
参考：**`DFSDM_I2S_Audio`** 或 **`DFSDM_SAI_Audio`**

### 7.2 精密称重 / 温度采集
```
Σ-Δ ADC (如 ADS1251) → DFSDM (Sinc4/Sinc5 + OSR=256) → DMA → 24-bit 精度数据
```
参考：**`DFSDM_SerialSPI`**（需把 SPI 测试数据换成真实 Σ-Δ 调制器）

### 7.3 ADC 过采样增强
```
内置 ADC 12-bit → DFSDM OSR=128 → 12 + log2(128)/2 ≈ 16-bit 有效精度
```
参考：**`DFSDM_InternalADC`**

### 7.4 同步采样（电机电流/电压）
```
Ia → Channel0 → FLT0 ┐
Ib → Channel1 → FLT1 ┘ 同步采样，电流环控制
```
参考：**`DFSDM_Synchronous_Regular`**

## 八、设计技巧

### 8.1 抗混叠 / 数据移位
```c
// 提高 OSR 可显著降低噪声；右移避免饱和
DFSDM_FilterInitStructure.DFSDM_FltOverSample          = 256;     // 高 OSR
DFSDM_ChannelInitStructure.DFSDM_ChDataRightBitShift  = 6;       // 防止溢出
```

### 8.2 看门狗 + Break
```c
// AWD 用于安全检测（如电表过流、称重超载）
DFSDM_FilterInitStructure.DFSDM_FltAWDHighThreshold = 32768;
DFSDM_FilterInitStructure.DFSDM_FltAWDLowThreshold  = -32768;
DFSDM_ITConfig(DFSDM_FLT0, DFSDM_IT_FLTx_AWDIE, ENABLE);

// 短路检测（短路持续 N 个时钟触发中断）
DFSDM_ChannelInitStructure.DFSDM_ChShortCircuitDetMode  = ENABLE;
DFSDM_ChannelInitStructure.DFSDM_ChSCDCntthreshold      = 220;
DFSDM_ITConfig(DFSDM_FLT0, DFSDM_IT_FLT0_SCDIE, ENABLE);
```

### 8.3 DMA 双缓冲
```c
// PDM 音频推荐用 DMA_Circular + 半满/全满切换
DMA_InitStructure.DMA_Mode = DMA_Mode_Circular;
while (!DMA_GetFlagStatus(DMA1, DMA1_FLAG_HT1));  // 等半满 → 清 HT1
while (!DMA_GetFlagStatus(DMA1, DMA1_FLAG_TC1));  // 等全满 → 清 TC1
```

### 8.4 注入触发同步多通道
```c
// TIM2 触发 → FLT0 和 FLT1 同步采样（电流电压同时）
DFSDM_JcTriggerSignal = DFSDM_JC_Trigger_TIM2;
// FLT1 同步跟随 FLT0
DFSDM_RcInitStructure.DFSDM_RcSynchronousMode = ENABLE;
```

## 九、调试小贴士

1. **数据全是 0？** 检查 `DFSDM_Cmd(ENABLE)` 与 `DFSDM_ChannelCmd` 是否都开了
2. **DMA 没数据？** 检查 `DMA_MuxChannelConfig(Mux, 107/108)` 和 `RCC_AHBPeriphClockCmd(RCC_AHBPeriph_DMA1, ENABLE)`
3. **RCIP 标志一直为 RESET？** 检查 `DFSDM_RcSoftStartConversion` 是否调用
4. **AWD 一直触发？** 调整 `Right_BitShift` 或阈值
5. **PDM 数据有噼啪声？** 增大 OSR / IOSR；确保 CKOUT 时钟与 PDM 麦克风匹配（典型 1~3 MHz）

| DFSDM_DATINx | GPIO 复用 AF3 / AF6 |
| AWD Break 信号 | AWDH_BK / AWDL_BK |
| Injected conversion | JC（JC_Channel0/1 + EXTI/TIM 触发） |
| Regular conversion | RC（连续 / 同步 / Fast / DMA） |

> 整体寄存器布局和 HAL API 风格非常接近 STM32H7 系列，从 STM32 移植到 CH32H417 DFSDM 的代码改动很小。

## 十一、学习路线建议

1. **`DFSDM_InternalStandardMode`** → 理解基本概念（内部数据流验证）
2. **`DFSDM_InternalDualMode` / `InternalInterleavedMode`** → 掌握三种数据打包模式
3. **`DFSDM_InternalADC`** → 理解"内部 ADC → DFSDM"高精度采集
4. **`DFSDM_SerialSPI`** → 接入外部 Σ-Δ 调制器（含 AWD）
5. **`DFSDM_DualFliter` / `Synchronous_Regular`** → 双滤波器协同
6. **`DFSDM_EXTITrigger` / `TIMTrigger`** → 触发式注入转换
7. **`DFSDM_I2S_Audio` / `SAI_Audio`** → PDM 麦克风音频应用（实战）
