# Strip_Games 玩法说明

一维 WS2812 灯带上的三款小游戏，可单人玩，也可两人各占一端对战。
本文档按当前固件的实际判定写（参数见 `User/game_config.h` 和 `User/main.c`），
和设计文档 [`CH32X033_WS2812_Arcade_Games.md`](CH32X033_WS2812_Arcade_Games.md)
里的早期版本略有差异（蜂鸣器改 PA2 / TIM2_CH3、切游戏改为双键 5 秒等）。

## 硬件

| 部件        | 引脚          | 说明                                    |
| ----------- | ------------- | --------------------------------------- |
| P1 按键     | PA0           | 内部上拉，按下接地                      |
| P2 按键     | PA1           | 内部上拉，按下接地                      |
| 无源蜂鸣器  | PA2           | TIM2_CH3 方波，负责全部音效             |
| WS2812 灯带 | 48 颗（默认） | 一维直线，DIN 接 PC7（TSSOP20 为 PC18） |

上电（复位）直接开始 **模式 0（能量对波）**，游戏中用双键手势或 USB 命令切游戏。

## 切换游戏

| 方式 | 操作                                                                                    |
| ---- | --------------------------------------------------------------------------------------- |
| 按键 | **同时按住 P1 + P2 5 秒**（`GAME_SWITCH_MS`）→ 蜂鸣器升调，切到下一款                   |
| 按键 | 按住期间不插入任何提示画面，游戏照常渲染、双键照常参与游戏；满 5 秒才切，提前松开即取消 |
| USB  | `python tools/stripctl.py --port COMx --game 0/1/2`                                     |
| USB  | 帧格式发 `0x10 SET_GAME`，payload 1 字节                                                |

只需按一次：切完会锁存，**松开两个键**后才允许再切一次（不会连跳）。

为什么是 5 秒：Game 1 的蓄力重击就是“按住”，而**两边同时按住蓄力**和
“双键切换”在硬件上是同一个事件。蓄力阀值只有 0.5 秒，把切换放到 5 秒
（= 10 倍）后，正常的对波操作永远碰不到；如果双方都按住超过 5 秒（已经远超
蓄力所需），就是这个切换手势本身。按住期间不做任何视觉干扰，只静默数满 5 秒。

`--games` 可以列出三款游戏和当前模式：

```sh
python tools/stripctl.py --port COM62 --games
```

切游戏会立即重置该游戏的局面并播报提示音。

## 模式 0 — 能量对波（双人对战）

**一句话**：两端对射，光弹相撞抵消，蓄力弹能吃掉普通弹，先打穿对方护盾者胜。

| 项       | 规则                                                                              |
| -------- | --------------------------------------------------------------------------------- |
| 双方     | P1 在灯带左端（第 0 颗），P2 在右端（第 47 颗）                                   |
| 短按发射 | 按下 ≥ 2 帧后松开 → 普通弹，速度 **0.75 颗/帧**                                   |
| 长按发射 | 按住 ≥ **0.5 秒**（30 帧）再松开 → 蓄力重击，速度 0.45 颗/帧（慢但穿甲）          |
| 碰撞     | 两发不同玩家的弹距离 < 1.2 颗时：同级**双双湮灭**；重击**吃掉**对方普通弹并继续飞 |
| 得分     | 弹飞到对方底线扣对方 1 格护盾，双方各 **5 格**                                    |
| 胜负     | 任一方护盾归零 → 胜利音效，然后**立即重开**（不显示比分）                         |

**看颜色**：

- 左端白点 = P1 正在蓄力（按住越久越亮，满 0.5 s 后全白）
- 右端同理给 P2
- 蓝色弹 = P1 普通弹（中间绿味），亮蓝绿 = P1 蓄力弹
- 红色弹 = P2 普通弹，亮橙 = P2 蓄力弹
- 左端蓝色血条 = P1 剩余护盾，右端橙色血条 = P2 剩余护盾

**策略**：普通弹快、蓄力弹穿，但蓄力要 0.5 秒且飞得慢；对轰时用重击清场，
趁对面蓄力空隙连发。

## 模式 1 — 拆弹轮盘（反应力，单人/双人抢拍）

**一句话**：红点高速来回弹，进绿区那一刻按键，越往后越快、绿区越小。

| 项   | 规则                                                                                                       |
| ---- | ---------------------------------------------------------------------------------------------------------- |
| 起点 | 红点从第 0 颗出发，速度 0.55 颗/帧                                                                         |
| 反弹 | 到 0 或 47 颗时反向，速度不变                                                                              |
| 绿区 | 以第 24 颗（灯带正中）为中心，初始半径 4 颗                                                                |
| 按键 | P1 或 P2 任意一个**按下沿**都算                                                                            |
| 命中 | 红点距中心 ≤ 绿区半径 → 算成功：速度 +0.12（**上限 1.6 颗/帧**），绿区半径 −1（**最小 1 颗**），播放胜利音 |
| 失手 | 红点不在绿区 → 爆炸音效，速度、绿区全部重置回初始值                                                        |
| 结束 | 没有终点，看你能连对多少次；绿区收到 1 颗、速度到上限就是极限难度                                          |

**看颜色**：绿色段 = 安全区，橙红点 = 待拆弹的红点。

**提示**：绿区最小后只有 1 颗灯，靠观察红点入射方向提前半帧按，比盯着中心更准。

## 模式 2 — 狭路相逢（1D 跑酷，双人协作）

**一句话**：玩家在第 3 颗，红色障碍从右往左冲，P1 跳、P2 射，别被撞到。

| 项      | 规则                                                                                 |
| ------- | ------------------------------------------------------------------------------------ |
| 玩家    | 固定在第 3 颗，白色；起跳期间变青色                                                  |
| P1 跳跃 | 按下沿触发，滞空 **22 帧（约 0.37 秒）**，期间对障碍免疫（距离 < 0.8 颗不判死）      |
| P2 射击 | 按下沿触发，从第 4 颗发出黄色激光，**1.4 颗/帧**向右飞，同一时刻只有一发             |
| 障碍    | 每 45~84 帧（约 0.75~1.4 秒）从第 47 颗刷出一个，最多同时 6 个，速度 0.35~0.62 颗/帧 |
| 击毁    | 激光距障碍 < 1.5 颗 → 障碍消失，激光同时消失（一发一个）                             |
| 失败    | 障碍到玩家附近且玩家没跳 → 失败音效，局面**全部重置**                                |
| 结束    | 无终点，活多久算多久                                                                 |

**看颜色**：白色/青色 = 玩家（地面/滞空），红色 = 障碍，黄色 = 激光。

**配合**：P2 优先打离玩家最近的障碍，P1 留跳给漏过来的那些；
P2 打掉障碍后激光消失，所以要一发一发地瞄，别连按。

## 音效对照

全部由 PA2 上的无源蜂鸣器方波产生（`sfx_push` 队列，1 帧起算）：

| 音效   | 触发                | 听感         |
| ------ | ------------------- | ------------ |
| 射击   | 普通弹 / 激光       | 两声上扬短音 |
| 重击   | 蓄力弹              | 三声低沉上扬 |
| 命中   | 扣血 / 碰撞 / 失手  | 两声下降低音 |
| 跳跃   | 起跳                | 两声上扬     |
| 切游戏 | 模式切换            | 高-停-更高   |
| 胜利   | 护盾打空 / 拆弹成功 | 4 音上行琶音 |

## 调参（`User/game_config.h`）

| 宏                     | 默认         | 作用                                                     |
| ---------------------- | ------------ | -------------------------------------------------------- |
| `GAME_LEDS`            | 48           | 灯带颗数；判定按实际颗数缩放（中心 = `GAME_LEDS/2`）     |
| `GAME_FPS`             | 60           | 帧率，所有"帧"参数按 `1000/GAME_FPS` 换算成时间          |
| `GAME_BRIGHTNESS`      | `0.25f`      | 全局渲染亮度（叠加在驱动亮度之上）                       |
| `GAME_SWITCH_MS`       | 5000         | 双键同时按住的切游戏时间，`-DGAME_SWITCH_MS=8000` 可加长 |
| `GAME_CHARGE_FRAMES`   | `FPS/2` = 30 | 蓄力弹的门槛                                             |
| `WSP_CURRENT_LIMIT_MA` | 350          | 帧级限流，防止 USB 口掉压                                |

改灯带长度时建议 24~120 颗：太短绿区/血条会挤在一起，太长亚像素移动变慢。
