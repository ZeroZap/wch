## 二、WCHNET 协议栈核心 API

源文件:`NetLib/wchnet.h`、`NetLib/eth_driver_RMII.c`

### 2.1 全局流程

每个例程的 `main()` 都遵循同一个最小骨架(以 `TCPServer/User/main.c` 为例):

```c
SystemCoreClockUpdate();
USART_Printf_Init(115200);
WCHNET_GetMacAddr(MACAddr);                  // 1. 从芯片 OTP 读 MAC
TIM2_Init();                                 // 2. 启动 10ms 周期定时器
i = ETH_LibInit(IP, GW, Mask, MAC);          // 3. 库初始化(MAC + 协议栈)
WCHNET_ConfigKeepLive(&cfg);                 // (可选) 保活参数
WCHNET_CreateTcpSocketListen();              // 4. 业务层创建 socket

while (1) {
    WCHNET_MainTask();                       // 5. 周期轮询(必须)
    if (WCHNET_QueryGlobalInt())
        WCHNET_HandleGlobalInt();            // 6. 处理全局/套接字中断
}
```

`ETH_LibInit()` 内部完成:

1. 组装 `struct _WCH_CFG cfg`,塞入 `net_send = ETH_TxPktChainMode`。
2. `WCHNET_ConfigLIB(&cfg)` → 检查各参数合法性。
3. `WCHNET_Init(ip,gwip,mask,mac)` → 初始化协议栈全局状态。
4. `ETH_Init(mac)` → 配置 MAC、PHY、RMII 引脚、中断。

`WCHNET_MainTask()`(`eth_driver_RMII.c:344`):

```c
void WCHNET_MainTask(void) {
    WCHNET_NetInput();       // 收包→协议栈
    WCHNET_PeriodicHandle(); // TCP 重传/超时
    WCHNET_QueryPhySta();     // PHY 状态轮询
    WCHNET_LinkProcessing(); // PHY 链路阶段处理
}
```

### 2.2 中断向量(`ch32v30x_it.c`)

```c
void TIM2_IRQHandler(void)  { WCHNET_TimeIsr(WCHNETTIMERPERIOD); }  // +10ms 心跳
void ETH_IRQHandler(void)   { WCHNET_ETHIsr(); }                    // MAC 中断入口
void EXTI9_5_IRQHandler(void){ ETH_PHYLink(); ... }                 // PHY 中断(可选)
```

> TIM2 周期 `WCHNETTIMERPERIOD` 默认 10ms(`eth_driver.h:46`),所有 ARP/TCP 超时/DHCP 心跳都基于此 tick。

### 2.3 关键配置结构体

```c
struct _WCH_CFG {                    // WCHNET_ConfigLIB 入参
    TxBufSize;     TCPMss;           // 发送缓冲 / TCP MSS(60~1460)
    HeapSize;      ARPTableNum;      // 协议栈堆; ARP 表项数(1~0x7F)
    MiscConfig0;   MiscConfig1;       // 各种开关(见 net_config.h)
    led_link; led_data;              // PHY/数据 LED 回调
    net_send;                        // 发送函数指针(MAC 驱动注入)
    net_recv;                        // 接收函数指针
    CheckValid = 0x12345678;         // 魔数
};
```

`MiscConfig0`(常用位):

- `bit0` TCP send copy
- `bit2` 删除最老 TCP 连接
- `bit8` 关闭 TCP 延迟 ACK(默认开启)

`MiscConfig1`:

- `bits0-7` socket 总数(<=31)
- `bit13` PING 开关
- `bits14-18` TCP 重传次数
- `bits19-23` TCP 重传周期(单位 50ms)
- `bit26` 硬件校验和

### 2.4 Socket 编程接口

```c
uint8_t  WCHNET_SocketCreat(uint8_t *socketid, SOCK_INF *socinf);
uint8_t  WCHNET_SocketConnect(uint8_t socketid);              // TCP 客户端
uint8_t  WCHNET_SocketListen (uint8_t socketid);              // TCP 服务端
uint8_t  WCHNET_SocketSend   (uint8_t id, uint8_t *buf, uint32_t *len);
uint32_t WCHNET_SocketRecvLen(uint8_t id, uint32_t *bufaddr); // 查询长度
uint8_t  WCHNET_SocketRecv   (uint8_t id, uint8_t *buf, uint32_t *len);
uint8_t  WCHNET_SocketClose  (uint8_t id, uint8_t mode);      // mode 见头文件
void     WCHNET_ModifyRecvBuf(uint8_t id, uint32_t addr, uint32_t len);
uint8_t  WCHNET_SocketUdpSendTo(uint8_t id, uint8_t *buf, uint32_t *slen,
                                uint8_t *sip, uint16_t port);
uint8_t  WCHNET_GetSocketInt(uint8_t id);                     // 取并清中断
uint8_t  WCHNET_SocketSetKeepLive(uint8_t id, uint8_t en);
uint8_t  WCHNET_SocketSetNagle   (uint8_t id, uint8_t en);
uint8_t  WCHNET_SetSocketTTL     (uint8_t id, uint8_t ttl);
```

`SOCK_INF` 在创建时主要设置:

| 字段             | 含义                                                          |
| ---------------- | ------------------------------------------------------------- |
| `ProtoType`      | `PROTO_TYPE_TCP / UDP / IP_RAW`                               |
| `SourPort`       | 本地端口;`IP_RAW` 时为协议号                                  |
| `DesPort`        | 目的端口                                                      |
| `IPAddr[]`       | 目的 IP(IP_RAW 必须填,UDP 可不填)                             |
| `RecvStartPoint` | 接收缓冲起点(可使用静态数组)                                  |
| `RecvBufLen`     | 接收缓冲长度                                                  |
| `AppCallBack`    | UDP 服务器的回调(传入 `(_SOCK_INF*, ipaddr, port, buf, len)`) |

### 2.5 中断状态

**全局** `WCHNET_GetGlobalInt()`:

```c
GINT_STAT_UNREACH   (1<<0)   // 不可达(ICMP 错误)
GINT_STAT_IP_CONFLI  (1<<1)   // IP 冲突
GINT_STAT_PHY_CHANGE (1<<2)   // PHY 状态变化
GINT_STAT_SOCKET     (1<<4)   // 有 socket 事件
```

**每个 Socket** `WCHNET_GetSocketInt(i)`:

```c
SINT_STAT_RECV       (1<<2)   // 收到数据
SINT_STAT_CONNECT    (1<<3)   // TCP 连接成功
SINT_STAT_DISCONNECT (1<<4)   // TCP 断开
SINT_STAT_TIM_OUT    (1<<6)   // TCP 超时断开
```

### 2.6 应用层扩展

| 功能        | API                                                                             |
| ----------- | ------------------------------------------------------------------------------- |
| DHCP 客户端 | `WCHNET_DHCPStart(cb)`、`WCHNET_DHCPSetHostname()`、`WCHNET_DHCPStop()`         |
| DNS 解析    | `WCHNET_InitDNS(server_ip, port=53)`、`WCHNET_HostNameGetIp(name, ip, cb, arg)` |
| TCP 保活    | `WCHNET_ConfigKeepLive()` + `WCHNET_SocketSetKeepLive(id, 1)`                   |
| ARP 重试    | `WCHNET_ARPRetryCfg(period, cnt, timeout)`                                      |
| PING 响应   | `WCHNET_PING_ENABLE = 1`(其它 socket 用 `PROTO_TYPE_IP_RAW`)                    |
| 地址转换    | `WCHNET_Aton("1.2.3.4", buf)`、`WCHNET_Ntoa(buf)`                               |

## 三、`net_config.h` 关键宏

> 在所有 `User/net_config.h` 中均可调,会重新计算 `WCHNET_MEMP_SIZE`、`WCHNET_RAM_HEAP_SIZE` 等。

| 宏                                   | 含义                        | 默认(以 TCPServer 为例) |
| ------------------------------------ | --------------------------- | ----------------------- |
| `WCHNET_NUM_IPRAW`                   | IP 层 raw socket 数         | 0                       |
| `WCHNET_NUM_UDP`                     | UDP socket 数               | 0                       |
| `WCHNET_NUM_TCP`                     | TCP socket 数               | 1                       |
| `WCHNET_NUM_TCP_LISTEN`              | TCP 监听 socket 数          | 1                       |
| `WCHNET_TCP_MSS`                     | TCP MSS                     | 1460                    |
| `WCHNET_NUM_POOL_BUF`                | POOL BUF 数                 | `NUM_TCP*2+2`           |
| `ETH_TXBUFNB` / `ETH_RXBUFNB`        | MAC 描述符数                | 2 / 7                   |
| `ETH_RX_BUF_SZE` / `ETH_TX_BUF_SZE`  | 单帧缓冲字节                | 1520                    |
| `WCHNET_PING_ENABLE`                 | 是否回应 PING               | 1                       |
| `TCP_RETRY_COUNT / TCP_RETRY_PERIOD` | TCP 重传                    | 20 / 10(×50ms)          |
| `CFG0_TCP_DEALY_ACK_DISABLE`         | 关闭 TCP 延迟 ACK(响应更快) | 1                       |
| `RECE_BUF_LEN`                       | 应用层 socket 接收缓冲      | `MSS*2`                 |
| `WCHNET_NUM_ARP_TABLE`               | ARP 表项数                  | 50                      |
| `WCHNETTIMERPERIOD`                  | tick 周期                   | 10ms(必须 <50)          |

工具链会在 `net_config.h` 末尾对 `RECE_BUF_LEN`、`POOL_BUF`、`TCP_MSS`、`ARP_TABLE` 等做合法性 `#error` 检查。

## 四、各例程精读

### 4.1 `TCPServer/` —— 最基础示例

`User/main.c` 关键点:

- `WCHNET_CreateTcpSocketListen()`:配置 `ProtoType=TCP`, `SourPort=1000`,调 `SocketCreat` 再 `SocketListen`。
- `WCHNET_DataLoopback(id)`(默认分支):直接从 `SocketInf[id].RecvReadPoint` 把数据原样 `SocketSend` 回去,**不拷走**;发送成功后再 `SocketRecv(id, NULL, &len)` 把已发数据从环形缓冲里丢掉。
- `WCHNET_HandleSockInt`:
  - `SINT_STAT_RECV` → 回环
  - `SINT_STAT_CONNECT` → `SocketSetKeepLive(1)` + `ModifiyRecvBuf` 切换到用户缓冲 + 把 socket id 记入 `socket[]` 数组
  - `SINT_STAT_DISCONNECT/TIM_OUT` → 从 `socket[]` 移除
- `WCHNET_HandleGlobalInt`:遍历 `0..MAX_SOCKET_NUM-1`,对每个 socket `GetSocketInt`,若有事件就分发。

> TCP Server 端维护 `socket[]` 数组是为了区分"谁连接、谁断开";TCPServer 例程里 LISTEN 是独立 socket id,客户端连接后会另外分配。

### 4.2 `TCPClient/`

和 Server 几乎对称,但:

- `WCHNET_CreateTcpSocket()`:把目的 IP 拷到 `TmpSocketInf.IPAddr`,调 `SocketConnect`。
- `SINT_STAT_TIM_OUT` 里**自动重连** `WCHNET_CreateTcpSocket()`。
- `for (i = 0; i < WCHNET_MAX_SOCKET_NUM; i++) WCHNET_CreateTcpSocket();` —— 一个例程开多个客户端。

### 4.3 `UDPClient/`

- 与 TCP 不同:UDP **没有 CONNECT/DISCONNECT**,但 `SockStatus` 里同样会触发 `SINT_STAT_CONNECT/DISCONNECT`,可当作状态指示。
- 默认开 4 个 UDP socket(`WCHNET_NUM_UDP=4`,见 `net_config.h`)。

### 4.4 `UDPServer/`

- UDP 服务端用 **回调方式**:`TmpSocketInf.AppCallBack = WCHNET_UdpServerRecv`。
- 收到 UDP 后由协议栈自动回调:`(socinf, ipaddr, port, buf, len)`,在回调里 `WCHNET_SocketUdpSendTo(socinf->SockIndex, buf, &len, ip_addr, port)` 即可回包(把 `ipaddr` 拆成 4 字节)。

### 4.5 `DHCP/`

- `IPAddr/GWIPAddr/IPMask` 初始全 0。
- `WCHNET_DHCPSetHostname("WCHNET")` 设置 DHCP 请求的主机名。
- `WCHNET_DHCPStart(WCHNET_DHCPCallBack)`,回调拿到 `arg` 即 DHCP 报文载荷(包含 IP/GW/Mask/DNS1/DNS2),成功后用这些值:
  - 把 IP/GW/Mask 写回全局
  - 关闭旧 socket(若有)
  - 用新 IP 重新 `WCHNET_CreateTcpSocket()`
- 失败返回 `NoREADY`,库自动重试。

### 4.6 `DNS/`

- 启动 DHCP → 回调成功 → `WCHNET_InitDNS(&p[12], 53)`(`p[12..15]` 是路由器下发的 DNS 服务器 IP)。
- `WCHNET_HostNameGetIp("www.wch.cn", RemoteIp, WCHNET_DNSCallBack, NULL)` 异步解析,结果在回调里 `printf`。
- `WCHNET_DNSStop()` 在回调里释放内部 socket。

### 4.7 `IPRaw_PING/`

- 使用 `PROTO_TYPE_IP_RAW`,`SourPort` 在 raw 模式下表示 **IP 协议号**(`1` = ICMP)。
- `PING.c` 是用户层 ICMP 实现:`InitPING()` 组 ICMP 头 + 计算校验和,`WCHNET_PINGCmd()` 用一个状态机推进:
  ```
  SOKE_CON → SEND → SEND_ERR/SEND_SUC → RECV_SUC/UNREACH → 5 次后 KEEP_NO
  ```
- 同时支持响应别人 PING(`Respond_PING`)。PHY 链路起来后置 `ICMPSuc = ICMP_SOKE_CON`,主循环里 `WCHNET_PINGCmd()` 自动开始 ping 序列。

### 4.8 `MAC_RAW/`

- 不链接 `wchnet` 库,只调用 `ETH_Init(mac)` + `MACRAW_Tx()`。
- 自己拼一个完整以太网帧(含目的 MAC、源 MAC、`0x0806` ARP 协议、ARP 头、18 字节 0x55 padding 至 64 字节最小长度),周期性 100ms 发一帧。
- 适用于纯链路层测试 / 做 ARP 探测。

### 4.9 `MQTT/`

- 目录里自带一份精简版 MQTT 客户端(MQTTConnectClient.c / MQTTPacket.c / MQTTSerializePublish.c / MQTTDeserializePublish.c / MQTTSubscribeClient.c / MQTTUnsubscribeClient.c / MQTTFormat.c)。
- 包装 `Transport_Open/Close/SendPacket` 把 WCHNET 的 socket 操作映射到 MQTT API 期望的接口。
- 流程:
  1. TCP 连上 broker(`Transport_Open`)
  2. 收到 `SINT_STAT_CONNECT` → `MQTT_Connect` 发 `MQTTSerialize_connect`
  3. 收到 broker 回 `CONNACK`(用 `MyBuf[0]>>4` 判包类型)→ `MQTT_Subscribe`
  4. 收到 `PUBLISH` → `MQTTDeserialize_publish` 解析 → `msgDeal` 处理 payload
- 心跳可选 `MQTT_Pingreq`,在 publishValid 触发时用 `MQTT_Publish` 发布。

### 4.10 `Mail/`

- 同时演示 **SMTP 发信 + POP3 收信**,需要分别连两个 TCP socket(`SocketSMTPIP`、`SocketPOP3IP`)。
- 邮件体 `MailBodyData` / 附件 `AttachmentData` 是用户自己拼 MIME。
- 收包处理靠 `WCHNET_CheckResponse(buf, CheckType)`,把 SMTP/POP3 服务器响应码与当前期望阶段对比(`CheckType = SMTP_CHECK_CNNT / POP_CHECK_CNNT …`)。
- `WCHNET_MailCmd(OrderType)` 是一个命令状态机,根据当前 OrderType 推进:"发送命令 → 检查响应 → 切下一阶段"。

### 4.11 `WebServer/`

- WCHNET 芯片**内置 Web 配置页面**,这个例程演示通过浏览器修改网络参数。
- 按键(PB6)按下 → `WCHNET_RestoreDefaults()` 把默认配置写回 Flash,系统重启。
- 正常启动:从 Flash 读 `BASIC_CFG_ADDR/PORT_CFG_ADDR/LOGIN_CFG_ADDR`,校验 flag → 解析出 IP/GW/Mask/MAC/DestIP/DestPort/SrcPort → `WCHNET_CreateTcpSocketListen(HTTP_SERVER_PORT)` + `WCHNET_CreateCfgSocket(mode, ...)` 创建数据通道(TCPS/TCPC)。
- `WCHNET_HandleSockInt`:在 HTTP 端口上收到数据 → `WCHNET_SocketRecv` 到 `HTTPDataBuffer` → `Web_Server()`(在 `HTTP/HTTPS.c`)处理网页请求,可能改 Flash、修改远端 socket 配置。

### 4.12 `ETH_IAP/`

- 升级工具是 `1_Tool_Doc/VerifyBinTool_WCHNET.exe`,走 TCP 把 bin 发下来。
- `User/IAP_Task.c`:
  - 收包 < `BIN_INF_LEN`:解析 `IAPFileParaCheck`(文件头、CRC、大小)。
  - 收包 >=:实际写入备份区 `BACKUP_IMAGE_START_ADD`(首先擦 108KB)。
- 上电流程(主循环之前):
  1. 按键(PA0)按下 → 进入 IAP 模式,创建 TCP socket 接收升级包。
  2. 否则读 Flash 中 `UPDATA_FLAG_STORAGE_ADD`,等于 `IMAGE_FLAG_UPDATE` 就把备份区拷到运行区(`IAPCopyFlashDeal`),最后用 Software IRQ 跳到 APP(`NVIC_SetPendingIRQ(Software_IRQn)`)。

### 4.13 `ETH_UART/` —— 以太网-串口透传

- 串口走 DMA 接收/发送(`bsp_uart.c`/`bsp_uart.h`)。
- 接收:轮询 `DMA1_Channel6->CNTR`(DMA 剩余计数)与上次比值 → 计算新字节数 → `WCHNET_SocketSend` 发到对端。
- 发送:`WCHNET_SocketRecv(socketid, uart_data_t.TX_buffer[tx_write], &len)` 把网口数据先放到串口发送缓冲 → `uartTx()` 启动 DMA。
- 注意:此例程仅支持 **10M 网络)(芯片位串口**,因为 100M 用到的引脚与某 UART 复用。

### 4.14 `8_UART_Server/` —— 8 串口网络服务器

- 192KB Flash / 128KB RAM 配置(用 WCHISPTool 烧录),`net_config.h` 中 `WCHNET_NUM_TCP=8`。
- `WCHNET_CreateTcpSocket()` 内部循环开 8 个 TCP 客户端(每个 `srcport++`,独立 `RecvStartPoint`)。
- 每个 `uart_data_t[i]` 独立维护一个串口的收发环形 DMA + 一个 socket ↔ UART 的双向映射(`uart1`↔`socket0`,…、`uart8`↔`socket7`)。
- `uartRxAndSendDataToETH` 一次性轮询 8 个 UART 的 DMA,新数据立即 SocketSend;`ETHRx` 把 socket 数据丢到 UART 的 DMA 缓冲。
- `CH32V307_DEBUG` 宏开启时把 `PRINT` 映射到 `printf`(用串口 1),关闭时全部空宏。

### 4.15 `ETH_Filter_Multicast/`

- 演示 MAC 层过滤(底层寄存器操作,`net_filter.c`):
  - `ETH_PerfectFilter(mac)` —— 加入精确匹配表
  - `ETH_HashFilter(mac)` —— 加入哈希表
  - `ETH_HashOrPerfectFilter(UNICAST_HashOrPerfectFilter / MULTICAST_HashOrPerfectFilter)` —— 模式选择
  - `ETH_SrcAddrPerfectFilter(mac)` —— 源地址过滤(在目的过滤的基础上)
  - `ETH_BroadcastFilter(ENABLE)` —— 广播过滤(需先初始化 MACA0HR/LR)
- 多播发送:`MulticastIPAddr = {224,1,1,10}`,调 `WCHNET_SocketUdpSendTo(socket, data, &len, MulticastIPAddr, 1000)` 即可。

### 4.16 `ETH_CFG/` —— 上位机配网

- 上位机 `1_Tool_Doc/WCH NET网络参数配置工具.exe` 通过 UDP 广播 `255.255.255.255:60000` 发到本机 `localPort=50000`。
- 收到配置 → `ParseConfigbuf(buf)` → 若配置有效 → `NVIC_SystemReset()` 重启 → 读 Flash 中最新参数 → 按 `CFG->type` 创建 TCPS/TCPC/UDPS/UDPC 中任一种 socket(`WCHNET_Create_Communication_Socket`)。
- Flash 中参数失效或首次上电:写默认配置 + `NVIC_SystemReset()`。
- 按键(PB6)可强制恢复默认。

## 五、常见编程模式总结

### 5.1 标准例程骨架

```c
mStopIfError(i);                        // 错误判断的统一入口
TIM2_Init();                            // 10ms 周期
i = ETH_LibInit(IPAddr,GWIPAddr,IPMask,MACAddr);
WCHNET_DHCPSetHostname("WCHNET");       // (可选)
i = WCHNET_DHCPStart(WCHNET_DHCPCallBack);  // (可选)
WCHNET_CreateTcpSocket();               // 业务 socket

while (1) {
    WCHNET_MainTask();
    if (WCHNET_QueryGlobalInt())
        WCHNET_HandleGlobalInt();
}
```

### 5.2 Socket 中断分发的"通用模板"

```c
void WCHNET_HandleGlobalInt(void) {
    u8 intstat = WCHNET_GetGlobalInt();
    if (intstat & GINT_STAT_PHY_CHANGE) { ... }
    if (intstat & GINT_STAT_UNREACH)     { ... }
    if (intstat & GINT_STAT_IP_CONFLI)    { ... }
    if (intstat & GINT_STAT_SOCKET) {
        for (i = 0; i < WCHNET_MAX_SOCKET_NUM; i++) {
            u8 s = WCHNET_GetSocketInt(i);
            if (s) WCHNET_HandleSockInt(i, s);
        }
    }
}
```

`WCHNET_HandleSockInt` 一般只关心四种事件:`SINT_STAT_RECV / CONNECT / DISCONNECT / TIM_OUT`。

### 5.3 接收数据的两种风格

```c
// 风格 A(回环,默认):直接用库内的环形缓冲
len = SocketInf[id].RecvRemLen;
WCHNET_SocketSend(id, (u8*)SocketInf[id].RecvReadPoint, &len);
if (ok) WCHNET_SocketRecv(id, NULL, &len);

// 风格 B(拷出来处理):先 RecvLen 拿到长度,再 Recv 到用户缓冲
len = WCHNET_SocketRecvLen(id, NULL);
WCHNET_SocketRecv(id, MyBuf, &len);
process(MyBuf, len);
```

### 5.4 修改接收缓冲到 RAM

在 `SINT_STAT_CONNECT` 中通常会做:

```c
WCHNET_ModifyRecvBuf(socketid, (u32)SocketRecvBuf[socketid], RECE_BUF_LEN);
```

把协议栈默认缓冲换成静态 RAM 数组,方便后续 `Recv` 拷走。

### 5.5 KEEPALIVE 用法

```c
struct _KEEP_CFG cfg = { .KLIdle = 20000, .KLIntvl = 15000, .KLCount = 9 };
WCHNET_ConfigKeepLive(&cfg);
WCHNET_SocketSetKeepLive(socketid, ENABLE);   // 在 CONNECT 时开启
```

空闲 20s 开始探活,间隔 15s,共 9 次失败才判死。

## 七、调试点滴

1. **库版本检查**:`WCHNET_LIB_VER`(头文件中的魔数)≠ `WCHNET_GetVer()` 实际值时,绝大多数例程都会 `printf("version error.\n")`,需重新对齐 `libwchnet.a` 与 `wchnet.h`。
2. **Pin 复用**:CH32V307 的某些引脚被 UART/ETH/PHY 共享,例如 100M 时 `8_UART_Server` / `ETH_UART` 只能用 10M 模式,需要在原理图与 `ETH_Configuration()` 里确认。
3. **PHY 地址**:`eth_driver.h` 中 `#define PHY_ADDRESS 1`,对应 PHY 硬件 AD 引脚上拉/下拉。
4. **多 socket 同协议**:`for (i = 0; i < WCHNET_MAX_SOCKET_NUM; i++) WCHNET_CreateTcpSocket();` 这种用法是 OK 的;但注意分配顺序。
5. **Flash 写入**:`WebServer`/`ETH_CFG`/`ETH_IAP` 都把配置写到 `PAGE_WRITE_START_ADDR` 之后的几页;按键触发恢复出厂是常见做法。
6. **DMA 与 `Recv` 吞吐**:`ETH_UART` 用 DMA 双缓冲,主循环里必须反复 `ETHRx` 才能把数据送完,否则 socket 缓冲会堆满触发丢包。
7. **MAC 过滤寄存器**:`ETH_Filter_Multicast` 提醒:开广播过滤前必须先初始化 `MACA0HR/LR`,否则 MAC 不知道自身地址。

## 附录 A:关键问答(随用随查)

### A.1 TCP KeepAlive 具体时长

TCPServer / TCPClient 例程默认值(`User/main.c` 内 `WCHNET_ConfigKeepLive(&cfg)`):

| 字段      | 值                 | 含义               |
| --------- | ------------------ | ------------------ |
| `KLIdle`  | **20000 ms**(20 s) | 空闲多久开始探活   |
| `KLIntvl` | **15000 ms**(15 s) | 每次探活间隔       |
| `KLCount` | **9** 次           | 连续失败多少次判死 |

- 从空闲到判死总耗时:`20 + 9 × 15 = 155 s`(≈ 2 分 35 秒)
- 默认使能位置:每个 socket 在 `SINT_STAT_CONNECT` 里调 `WCHNET_SocketSetKeepLive(socketid, ENABLE)`
- 激进配置参考:`KLIdle=5000、KLIntvl=3000、KLCount=3` → 5 s 起探,最坏 14 s 断开
- 相关但不同的概念:`TCP_RETRY_PERIOD`(×50ms,默认 10=500ms)和 `TCP_RETRY_COUNT`(默认 20)是 **TCP 数据重传**,不是 KeepAlive,两者都依赖 `WCHNETTIMERPERIOD=10ms` 的 tick

### A.2 MAC_RAW 能否适配 lwIP

**结论:可行,而且几乎是现成的。** `MAC_RAW/ETH_Driver/` 提供的 MAC+PHY 驱动恰好就是 lwIP `netif` 期望的形态。

**对照表**

| lwIP 接口                | 现有驱动对应                                                                             |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| `low_level_output(pbuf)` | `ETH_TxPktChainMode(len, *buf)`,即 `cfg.net_send`;MAC_RAW 里直接是 `MACRAW_Tx(buf, len)` |
| `low_level_input()` 取帧 | `RecDataPolling()`(轮询)/ `WCHNET_ETHIsr()`(中断)                                        |
| DMA 描述符               | `DMATxDscrTab[ETH_TXBUFNB] / DMARxDscrTab[ETH_RXBUFNB]` 已分配                           |
| 帧缓冲                   | `MACTxBuf[] / MACRxBuf[]` 已分配(`1520 × N`)                                             |
| PHY 协商                 | `ETH_PHYLink()` 已实现                                                                   |
| PHY 寄存器读写           | HAL `ETH_ReadPHYRegister / WritePHYRegister`                                             |
| 时钟 tick                | TIM2 → `WCHNET_TimeIsr` → `LocalTime`(ms),直接给 lwIP `sys_now()`                        |

**最小移植步骤(伪代码)**

```c
// 1) 沿用 MAC_RAW 的 ETH_Driver,不再链接 libwchnet.a
// 2) sys_now() 复用 LocalTime
u32_t sys_now(void) { return LocalTime; }

// 3) low_level_output
static err_t low_level_output(struct netif *netif, struct pbuf *p) {
    if (p->tot_len > ETH_TX_BUF_SZE) return ERR_BUF;
    ETH_TxPktChainMode(p->tot_len, (u32_t *)p->payload);
    return ERR_OK;
}

// 4) low_level_input:取一帧→pbuf→提交给 netif
static void low_level_input(struct netif *netif) {
    struct pbuf *p = pbuf_alloc(PBUF_RAW, frame_len, PBUF_RAM);
    memcpy(p->payload, frame_buf, frame_len);
    netif->input(p, netif);
}

// 5) 主循环:不再 WCHNET_MainTask,而是
while (1) {
    ethernetif_poll(&g_netif);       // 自己实现的收包入口
    sys_check_timeouts();            // lwIP 协议栈 timer
}
```

**需要在 `eth_driver_RMII.c` 改/删的点**

1. TIM2 中断保留,但只用来给 `LocalTime += 10`,不再喂 WCHNET
2. 删除 `WCHNET_ConfigLIB / WCHNET_Init`,相关 `cfg.*` 字段失效
3. `ETH_TX_BUF_SZE / ETH_RX_BUF_SZE / ETH_TXBUFNB / ETH_RXBUFNB` 保留(决定 DMA 描述符与缓冲)
4. PHY 协商保留 `ETH_PHYLink()`,但 `WCHNET_CheckPHYPN / QueryPhySta` 内部依赖 WCHNET 状态,直接砍掉,主循环只调 `ETH_PHYLink()`
5. `RecDataPolling()` 是 WCHNET 内部状态机,挪走;改写简单循环 `while (rx_desc_owned_by_cpu) { … }` 把帧丢给 lwIP
6. `ETH_IRQHandler` 原来调 `WCHNET_ETHIsr()`,改为:读 `ETH->DMASR` 清中断 + 置"有包"标志,实际取帧放主循环

**RAM 占用估算**

- lwIP 默认配置(MEM_SIZE=1600 / PBUF_POOL_SIZE=16 / TCP_MSS=1076 / TCP_WND=4*MSS)≈ **8~10 KB**
- MAC 描述符 + 缓冲 ≈ `2×1520 + 7×1520` ≈ **13.6 KB**
- CH32V307 **VCT6**(64 KB RAM):够用,建议 `TCP_MSS=1076`
- CH32V307 **VCT7**(128 KB RAM):宽松,可开 `TCP_MSS=1460`,吞吐更好

**注意**

- lwIP `tcp_write` 默认不会自动 `tcp_output`,需要在合适时机主动 `tcp_output()`
- ETH 中断里**必须读清 DMA 状态寄存器**,否则会一直进中断
- WCHNET 是闭源静态库,要换 lwIP 时 `MQTT / DHCP / Mail / WebServer` 等"应用层"代码可以复用,但底下协议栈必须从 MAC_RAW 重做,不能直接改 ETH_UART / 8_UART_Server

**对照表:启动算法对比**

| 例程                                 | 协议栈          | 能否换 lwIP                                |
| ------------------------------------ | --------------- | ------------------------------------------ |
| TCPServer / TCPClient / UDP…         | WCHNET(闭源)    | ❌ 改不动,只能从 MAC_RAW 重做              |
| **MAC_RAW**                          | 无,直接打裸帧   | **✅ 最佳起点**                            |
| ETH_UART / 8_UART_Server             | WCHNET          | 想换 lwIP 得大改                           |
| MQTT / Mail / DHCP / DNS / WebServer | WCHNET + 用户态 | 应用层代码可复用,协议栈必须从 MAC_RAW 重建 |

**移植文件清单**

### B.1 模块本质与定位

- **不是 PHY 芯片**,而是**闭环模组**:内部 MCU 是**沁恒 CH579**(Cortex-M0 内核,32M 主频) + MAC + PHY + TCP/IP 协议栈 + 网页/AT 配置界面。
- **协议栈与本目录同根同源**:TAS-LAN-751 内部跑的也是 WCH 的 WCHNET 协议栈,API 命名、配置结构(`SOCK_INF`、`net_config.h`、`WCHNET_*`)与 CH32V307 例程几乎完全一致。换句话说,本目录的 ETH 例程,就是 CH579/CH32V307 系列 WCHNET 的官方参考实现;模组只是把 CH579 的能力封装成一个串口透传产品。
- **对外只有两个接口**:TTL 3.3V 串口 + RJ45 网口;尺寸 53.5 × 23 × 21.6 mm(含网口/插针)。
- **用途**:MCU 只负责发串口数据 → 模组负责打包进以太网。MCU 端不需要跑协议栈。
- 与 CH32V307 例程的关系:**例程 = WCHNET 在 CH32V307(RISC-V) 上的官方参考实现;模组 = 同一套 WCHNET 跑在 CH579(M0) 上,封装成 TTL 串口透传产品。**两者适用于不同工程场景:

  |          | 模组 (TAS-LAN-751)       | CH32V307 例程          |
  | -------- | ------------------------ | ---------------------- |
  | 芯片     | CH579 (M0)               | CH32V307 (RISC-V)      |
  | 协议栈   | WCHNET(同源)             | WCHNET                 |
  | 用户接口 | 串口 AT + 网页           | 直接调 C API           |
  | 适用     | 快速集成、不改协议栈细节 | 自定义应用层、源码可控 |

### B.5 AT 指令一览(便于写 MCU 侧的协议代码)

| 类别     | 指令           | 功能                                          |
| -------- | -------------- | --------------------------------------------- |
| 管理     | `+++`(无回车)  | 进入指令模式                                  |
| 管理     | `ATO`(带回车)  | 退出指令模式                                  |
| 管理     | `AT+CFUN`      | 模块重启                                      |
| 管理     | `AT&F`         | 恢复出厂                                      |
| 管理     | `AT&W`         | 保存当前配置                                  |
| 管理     | `AT+DSCTIME`   | 查询/设置长连接失败重启时间                   |
| 信息查询 | `AT+CGMR`      | 查询版本信息                                  |
| 信息查询 | `AT+ALL`       | 查询所有配置信息                              |
| 串口参数 | `AT+UARTCFG`   | 查询/设置串口参数                             |
| 网络参数 | `AT+IPCONFIG`  | 查询/设置本地网络参数(IP/Mask/GW/DNS)         |
| 网络参数 | `AT+MACADDR`   | 查询/设置模块 MAC                             |
| 网络参数 | `AT+TCPCFG`    | 查询/设置远程网络参数(目标 IP/端口、工作模式) |
| 注册包   | `AT+REGIS`     | 查询/设置注册包信息                           |
| 心跳包   | `AT+KEEPALIVE` | 查询/设置心跳包信息                           |
| 多路协议 | `AT+SENDID`    | 查询/设置多路数据协议(对应多 Client)          |
| 成帧     | `AT+UARTTIME`  | 自定义打包时间                                |

**MCU 侧协议代码思路**(若用串口 AT 配置):

```c
// 1. 串口以 9600,8,N,1 打开,发送 "+++" 模组会回 "Enter AT Mode" 之类的 ready
// 2. 发指令均需以 "\r\n" 结尾
// 3. 设 IP:    "AT+IPCONFIG=STATIC,192.168.0.80,255.255.255.0,192.168.0.1,114.114.114.114\r\n"
// 4. 设模式:  "AT+TCPCFG=TCPC,192.168.0.73,10123\r\n"
// 5. 保存:    "AT&W\r\n"
// 6. 重启:    "AT+CFUN\r\n"
// 7. 退指令模式: "ATO\r\n"
```

### B.6 与 ETH 例程的"选型"决策表

| 场景                                                                      | 推荐路径                                             |
| ------------------------------------------------------------------------- | ---------------------------------------------------- |
| 产品快速上市、不希望画 PHY/MAC 板                                         | **用 TAS-LAN-751 模组**,串口 AT 配置,几小时搞定网络  |
| 需要自定义协议(私有二进制、长连接保活策略、加密、QOS>0 的 MQTT)           | 用模组受限 → 自己基于 CH32V307 + WCHNET 例程做       |
| 需要 lwIP + 完整 TCP/IP 灵活控制                                          | 例程的 `MAC_RAW` 改 lwIP(见附录 A)                   |
| 需要跑 Modbus 网关                                                        | 模组自带 Modbus TCP↔RTU 转换                         |
| 需要支持大量 Client(>3)                                                   | 例程(`TCPServer`)可配置;模组限 3 路                  |
| 需要 HTTP Server(模组) vs HTTP Client(需要外部资源)                       | 例程做 Server、模组做 Client                         |
| 成本敏感、体积小                                                          | 用模组(整机 ~53mm 长,免去 PHY/MAC 物料)              |
| 已有 MCU 串口被占用、需要并入主控                                         | 例程路线(CH32V307 自带以太网)                        |
| **想改协议栈内部行为**(调整 KeepAlive 时间、socket 数量、改 TCP 重传策略) | WCHNET 同源,拿例程的 C 代码基本可原样移到 CH579 工程 |

### B.7 调试速查(对应文档 §6)

| 问题         | 文档对应                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------- |
| 打不开网页   | §6.1:11 条排查清单(串口占用 / 网段不匹配 / DHCP 直连电脑 / 浏览器 / MAC 冲突 / 网口灯状态等) |
| 串口无法通信 | §6.2:检查 COM 口、波特率(默认 9600),CFG 拉低 3s 恢复出厂                                     |

### B.8 一句话总结

> **TAS-LAN-751 = ETH 例程所有"网络连通"功能的"开箱即用版本"**。内部就是 WCH 的 CH579 跑 WCHNET 协议栈,API 与本目录 CH32V307 例程完全同源(只是 CPU 内核不同)。
>
> - 优先选模组:网页配置 + AT 命令 + 串口透传 + Modbus 网关能解决的场景
> - 回到 `CH32V307 + WCHNET` 例程:需求触及模组能力边界(自定义 MQTT QOS、源码改动、HTTP Server 自定义页面、多路 Client>3、lwIP 生态)
> - 想自己改协议栈内部行为:由于 WCHNET 同源,可以把例程的 C 代码基本原样移植到 CH579 工程

- **参考依据**:文档全文 50 页,本文关键参数均来自原 PDF;具体 AT 指令格式需进一步看官方《AT 指令集》补充。
